# Vault .md trên web — ABM

Trình xem vault Obsidian (hoặc bất kỳ thư mục `.md` nào) chạy trên trình duyệt. Một file `index.html` (~54 KB), không máy chủ, không tài khoản, không cài đặt. File không rời khỏi máy: trình duyệt đọc tại chỗ.

## Tính năng
- **Mở vault**: chọn thư mục, kéo thả thư mục, hoặc dùng vault mẫu. Chrome / Edge trên máy tính nhớ vault lần trước và cho phép **sửa, lưu thẳng vào file (Ctrl S), tạo ghi chú mới**. Trình duyệt khác và điện thoại: chỉ đọc.
- **Markdown** đầy đủ: tiêu đề, bảng, trích dẫn, mã, checklist, ảnh trong vault, frontmatter.
- **Liên kết hai chiều** `[[Tên]]`, `[[thư mục/Tên]]`, `[[Tên|bí danh]]`, `[[Tên#Mục]]`, nhúng `![[Tên]]`; bảng **Liên kết ngược** kèm ngữ cảnh, **Liên kết đi**, liên kết chưa có file.
- **Sơ đồ liên kết động** toàn vault (Ctrl G): vật lý lực như Obsidian, kéo nút, phóng, lọc nút, thẻ thành nút, ẩn nút mồ côi, chỉnh lực đẩy / độ dài / cỡ nút, màu theo thư mục, bấm nút để mở.
- **Sơ đồ cục bộ** của ghi chú đang mở (2 bậc láng giềng) ở cột phải.
- Cây thư mục có gập/mở, lọc file, **tìm nhanh Ctrl K** theo tên và nội dung, thẻ `#tag`, dàn ý, tải file .md, giao diện sáng / tối, điện thoại.

## Phím tắt
Ctrl K tìm · Ctrl G sơ đồ · Ctrl S lưu · Esc đóng.
